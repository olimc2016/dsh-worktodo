子待办 + 备注：四个方案，三档宽度

这一页是 静态 mockup：不改应用代码，不读写任何数据，纯前端假数据。四个方案 —— 现状、A 行内展开、B 右侧抽屉、A+B 组合（推荐） —— 用同一组示例待办， 分别在 320 / 420 / 600px 的面板宽度下各渲染一份。行、chip、勾选框、动效都沿用面板的视觉语言； 勾选、展开、改名、添加、备注输入、抽屉开关都是真的能点的，刷新后回到初始假数据。

A static, clickable mockup for subtasks and notes in the dsh-worktodo panel — no app code is touched. The same sample rows are rendered in four schemes (current, A inline, B drawer, A+B recommended) at 320 / 420 / 600 px. Checking subtasks, expanding a list, renaming, adding, typing notes and opening the drawer are all live; reloading resets the fake data.

推荐 内嵌 subtasks[]（≤50 条/父）+ 现有 notes（2000 字，纯文本）： 子待办用 A 行内展开，备注用 B 右侧抽屉。勾完最后一条不自动完成父项，只给一次轻提示；勾父项级联勾子项，取消父项不级联。 Embedded subtasks + the existing notes field. Inline list for subtasks, drawer for notes. No auto-complete on the last subtask; parent check cascades down, parent uncheck does not.

设计摘要（细节见 review 文档）

Data model

子待办内嵌：{id,title,done,order}，≤50 条/父；子项不带日期/优先级/项目。

备注沿用顶层 notes：纯文本、保留换行、2000 字；缺省为 [] / ''。

Interaction

A：点 2/3 行内展开，勾选/改名/删除/新增都不离开上下文。

B：备注图标 → 右侧抽屉，多行 textarea 有足够空间；A+B 各管一件事。

Linkage

勾父项 → 子项全勾；取消父项 → 只取消父项。勾完最后一条 不自动完成，只提示「要勾掉这条吗？」。

统计只算父项；搜索带备注（并建议带子项标题）；子项不参与逾期/分组。
